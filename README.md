# Caixa Certo

Gestão financeira simples para pequenos negócios.

## Visão geral

Acompanhe entradas, saídas e o resultado do mês. A aplicação apresenta um painel responsivo com dados demonstrativos e ações básicas de operação.

## Recursos

- Dashboard com indicadores principais.
- Busca na atividade da conta.
- Ação de adicionar novo registro.
- Layout responsivo para desktop e celular.
- Feedback visual após ações.

## Tecnologias

HTML, CSS e JavaScript sem dependências externas.

## Executar localmente

```bash
python3 -m http.server 8000
```

Abra `http://localhost:8000`.

## Evolução planejada

- Persistência em banco de dados.
- Autenticação e perfis de acesso.
- Relatórios e integrações com serviços externos.
